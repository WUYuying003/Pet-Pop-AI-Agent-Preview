# PetPop AI Preview

PetPop 是一个面向普通宠物主的 AI 宠物内容经营 Agent。它基于宠物画像、历史内容表现和平台目标，把“今天发什么”转化为可解释、可编辑的每日任务，并通过用户反馈持续完善宠物 IP 画像。

## 在线体验

部署后链接将在此处更新。无需登录，所有内容均为前端模拟数据。

推荐体验路径：

1. 在首页点击“开始今日任务”
2. 确认平台、表达风格与素材
3. 生成内容方案，并查看 AI 的生成依据
4. 编辑、重新生成或采用方案
5. 查看任务完成后更新的宠物画像

## 本地运行

无需安装依赖：

```bash
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173`。

## 演示边界

- 本仓库只包含静态前端、精选视觉素材和模拟数据
- 不包含生产环境 API、登录逻辑、用户凭据或服务端代码
- AI 生成过程为可交互的产品体验模拟，重点展示输入、上下文、输出和人工反馈闭环
- 产品默认不自动发布内容，用户始终拥有编辑权与最终决定权

## 技术说明

原型使用原生 HTML、CSS 与 JavaScript 实现，可直接部署到 GitHub Pages。没有后端依赖，也不会上传或持久化访客数据。
